# Changelog

## Initial GitHub upload
- Added the first playable browser prototype.
- Added a voxel landscape, first-person movement, mining and block placement.
- Added the Heart Loom campaign premise and four-dimension world identity.
- Added an initial shader-inspired lighting and atmosphere pass.
- Added a GitHub Pages deployment workflow.
- Documented the safe JSON mod-pack direction.

## Prototype status
This is an early playable foundation, not the full planned open-world RPG. Persistent shared multiplayer, complete campaign quest chains, extensive creature AI, advanced automation and full mod scripting remain future work.
